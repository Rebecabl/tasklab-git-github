## 🎯 1. Matriz de Avaliação da Prática (Total: 10,0 Pontos)

A avaliação da atividade prática equilibra o desempenho **individual** do estudante e a capacidade de **trabalho colaborativo em equipe**.

## ⏰ 3. Planejamento da Aula (Dois Modelos de Aplicação)

### 📌 Roteiro A: Encontro Único de 100 Minutos
Ideal para laboratórios em bloco duplo contínuo.

- **00h00 - 00h15 (15 min) — Abertura e Conceitos:**  
  *Atividade:* A professora contextualiza o Git no mercado, apresenta o TaskLab e o conceito de ramificação (GitHub Flow).
- **00h15 - 00h25 (10 min) — Clonagem e Ambiente:**  
  *Atividade:* Os alunos clonam o repositório `tasklab-git-github`, abrem no VS Code e aceitam os convites.
- **00h25 - 00h45 (20 min) — Branches e Commits:**  
  *Atividade:* Cada aluno cria sua branch individual (`git checkout -b feature/equipeXX-nome`), implementa sua alteração e registra commits semânticos.
- **00h45 - 01h00 (15 min) — Pull Requests e Code Review:**  
  *Atividade:* Envio da branch (`git push`), abertura de PR com template preenchido e revisão cruzada entre pares.
- **01h00 - 01h20 (20 min) — Dinâmica de Conflito de Merge:**  
  *Atividade:* A professora demonstra ao vivo no projetor o conflito gerado por dois alunos em `docs/MENSAGENS_TURMA.md` e ensina a resolução manual.
- **01h20 - 01h35 (15 min) — GitHub Projects e Finalização:**  
  *Atividade:* Vinculação dos PRs às Issues com `Closes #ID`, movimentação dos cards no quadro Kanban e verificação do merge na `main`.
- **01h35 - 01h40 (5 min) — Encerramento e Feedback:**  
  *Atividade:* Atualização local coletiva com `git pull origin main` e considerações finais da professora.

---

### 📌 Roteiro B: Dois Encontros de 50 Minutos
Ideal para turmas com aulas divididas em dias separados na semana.

#### 📅 Encontro 1 (50 Minutos) — Fundamentos, Branches e Desenvolvimento Local
- **10 min — Demonstração da Professora:**  
  Apresentação do TaskLab, explicação do fluxo de trabalho centralizado e demonstração do ciclo `clone -> branch -> commit`.
- **15 min — Prática dos Estudantes (Parte 1):**  
  Clone do repositório, configuração de ambiente e criação das branches individuais por equipe.
- **20 min — Prática dos Estudantes (Parte 2):**  
  Desenvolvimento das atividades individuais de código (`js/`, `css/`, `pages/`), inspeção com `git status`/`git diff` e commits locais.
- **5 min — Sincronização:**  
  Envio das branches ao GitHub (`git push -u origin feature/...`) e verificação das ramificações criadas.

#### 📅 Encontro 2 (50 Minutos) — Pull Requests, Code Review, Conflitos e Gestão Ágil
- **10 min — Demonstração da Professora:**  
  Como abrir um PR profissional, uso de templates, regras de aprovação e o valor do Code Review.
- **15 min — Prática dos Estudantes (Parte 1):**  
  Abertura dos PRs individuais, preenchimento do checklist e realização mútua do Code Review entre os colegas.
- **15 min — Dinâmica Prática de Conflito:**  
  Execução do exercício prático de conflito planejado no arquivo `docs/MENSAGENS_TURMA.md`, identificação dos marcadores e resolução pelo aluno afetado.
- **10 min — Gestão Ágil e Fechamento:**  
  Acompanhamento do quadro Kanban no *GitHub Projects*, merge dos PRs aprovados pela professora e atualização final do repositório com `git pull origin main`.
