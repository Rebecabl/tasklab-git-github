Sobre o TaskLab

Um laboratório prático para vivência real de controle de versão e trabalho em equipe.

🎯 Propósito Educacional

O TaskLab — Gerenciador de Tarefas foi idealizado como projeto-base para a atividade prática da disciplina Tópicos Especiais em Engenharia de Software I — Unidade II, ministrada pela professora Rebeca Barbosa Lourenço.

O foco da aplicação não reside na complexidade arquitetural do software, mas na experiência prática das rotinas profissionais de controle de versão, colaboração distribuída e governança de código utilizando Git e GitHub.

🚀 Habilidades Desenvolvidas na Prática

  • Clonagem e Configuração: Obtenção do repositório remoto e ajuste de credenciais do Git.
  • Trabalho em Branches: Criação de ramificações isoladas para cada membro e funcionalidade (GitHub Flow).
  • Commits Semânticos: Padronização de mensagens de commit seguindo Conventional Commits.
  • Pull Requests & Code Review: Abertura de PRs com templates estruturados e revisão mútua entre pares.
  • Resolução de Conflitos: Identificação, análise manual e resolução colaborativa de conflitos de merge.
  • Gestão Ágil: Uso de GitHub Issues e GitHub Projects para acompanhamento do ciclo de vida das tarefas.

💻 Tecnologias Empregadas

A aplicação utiliza deliberadamente tecnologias web fundamentais, sem ferramentas de build ou frameworks pesados, garantindo rápida execução em qualquer máquina:

  • HTML5 — Estrutura semântica e acessível.
  • CSS3 — Estilização modular com variáveis CSS e layout responsivo via Flexbox e Grid.
  • JavaScript Puro (Vanilla JS) — Manipulação de DOM e lógica de negócios sem dependências externas.
  • LocalStorage — Persistência de dados diretamente no navegador do usuário.
  • Git & GitHub — Versionamento e colaboração em equipe.
